# EduPrep Phase 1 Source of Truth

Upload these files to the repository and use `00_SOURCE_OF_TRUTH.md` as the authoritative Phase 1 specification.

The first deployment deliberately does NOT integrate ALOC. Seed/demo questions are used so the product can go live and be tested first.

Future ALOC integration must happen server-side through a content adapter.

Never commit real API tokens. Use `.env` locally and deployment secrets in the hosting platform.
